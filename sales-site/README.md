# DomHub Sales Site

Отдельный статический сайт для продвижения и продаж DomHub. Он не подключен к `frontend/` SPA и не меняет маршруты приложения.

Версия использует:

- Three.js `0.184.0` для hero WebGL-сцены;
- GSAP `3.15.0` + ScrollTrigger для scroll-reveal;
- нативный fallback canvas, если CDN недоступен;
- `prefers-reduced-motion` для пользователей с отключенной анимацией.

## Как открыть

Откройте `index.html` в браузере или раздайте папку любым статическим сервером.

## Что менять перед публикацией

- `script.js`: замените `sales@domhub.su` на рабочий адрес отдела продаж.
- `index.html`: при необходимости обновите оффер, CTA и пилотные сроки.
- `styles.css`: визуальная система сайта изолирована от приложения.
