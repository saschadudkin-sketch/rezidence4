# DomHub v2 PRD

## Обзор

DomHub v2 — multi-tenant SaaS-платформа для управления операционными процессами жилых комплексов. Платформа объединяет доступ, заявки, уведомления, рабочие процессы персонала и управленческую прозрачность.

## Цель

Запустить сфокусированную и коммерчески жизнеспособную версию v2 для первых платящих клиентов без расползания продукта.

## Базовая формула продукта

`доступ + заявки + уведомления + staff workflow + audit`

## Целевые клиенты

- управляющие компании;
- девелоперы;
- операторы нескольких объектов;
- premium и business-class ЖК.

## Основные пользователи

- жители;
- охрана;
- консьержи;
- technician;
- contractor;
- property_admin;
- management_company_admin;
- platform_admin.

## Ключевой scope v2

- multi-tenant foundation;
- структура объекта;
- роли и scope доступа;
- гостевые пропуска и QR;
- заявки, SLA и assignment;
- staff workspace;
- объявления и документы;
- push, SMS, Telegram;
- packages;
- onboarding;
- базовая аналитика;
- audit trail.
