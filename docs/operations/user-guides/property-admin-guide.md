# Руководство администратора объекта

Администратор объекта отвечает за:
- настройку staff и ролей внутри объекта;
- контроль заявок и SLA;
- управление объявлениями, документами, уведомлениями;
- контроль подрядчиков;
- просмотр аналитики и аудита;
- оперативное решение инцидентов на уровне объекта.

## Ежедневные задачи

- проверка очереди заявок;
- контроль просрочек;
- проверка критичных уведомлений;
- управление staff assignments;
- контроль доступов.

## Периодические задачи

- пересмотр ролей и прав;
- проверка подрядчиков;
- контроль качества исполнения;
- сверка аналитики и отчетности.
