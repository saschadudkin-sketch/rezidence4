# Инструкция для охраны

Охрана использует DomHub для:
- проверки пропусков;
- сканирования QR;
- фиксации admit/deny;
- просмотра журнала посещений;
- обработки инцидентов, связанных с доступом.

Охрана не должна:
- смотреть лишние данные жителей;
- менять роли и настройки;
- использовать доступ вне служебной необходимости.
