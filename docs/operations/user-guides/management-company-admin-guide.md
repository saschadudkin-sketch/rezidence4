# Руководство администратора управляющей компании

Администратор УК отвечает за:
- контроль нескольких объектов;
- агрегированную аналитику;
- стандарты SLA;
- контроль staff-модели;
- контроль качества работы подрядчиков;
- эскалации между объектами.

## Основные функции

- просматривать KPI по объектам;
- сравнивать SLA и backlog;
- управлять общими процессами и шаблонами;
- контролировать проблемные объекты;
- взаимодействовать с платформенной поддержкой.
