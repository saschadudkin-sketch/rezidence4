# Руководство по запуску нового объекта DomHub

## 1. До запуска

Нужно собрать:
- карточку объекта;
- структуру корпуса/подъезды/квартиры;
- список staff;
- список жителей для импорта;
- список подрядчиков;
- правила SLA;
- категории заявок;
- каналы уведомлений;
- бренд-настройки объекта.

## 2. Настройка

- создать объект в платформе;
- импортировать структуру и пользователей;
- назначить роли;
- включить нужные модули;
- настроить уведомления;
- проверить права доступа;
- загрузить документы и объявления.

## 3. Проверка готовности

- тест логина;
- тест создания заявки;
- тест пропуска и QR;
- тест уведомления;
- тест staff queue;
- тест аналитики и журнала аудита.

## 4. День запуска

- назначить ответственных;
- открыть каналы поддержки;
- провести инструктаж staff;
- контролировать первые операции в системе.

## 5. Первая неделя

- отслеживать инциденты;
- корректировать роли и права;
- проверять доставку уведомлений;
- собирать обратную связь.
