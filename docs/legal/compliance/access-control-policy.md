# Политика управления доступом DomHub

## 1. Цель

Настоящая Политика определяет правила выдачи, изменения, контроля и отзыва доступов в платформе.

## 2. Основные принципы

- минимально необходимый доступ;
- доступ по роли и scope;
- разделение обязанностей;
- журналирование критичных действий;
- регулярный пересмотр прав.

## 3. Роли

Базовые роли:
- resident
- security
- concierge
- technician
- contractor
- property_admin
- management_company_admin
- platform_admin

## 4. Scope доступа

Доступ ограничивается:
- объектом;
- корпусом/подъездом;
- типом заявок;
- специализацией;
- назначенными задачами;
- уровнем доступа к чувствительным данным.

## 5. Выдача доступа

Доступ выдается:
- при запуске объекта;
- по запросу уполномоченного администратора;
- после подтверждения роли и необходимости доступа.

## 6. Временный доступ

Для подрядчиков и внешних участников доступ должен быть по возможности временным, ограниченным и контролируемым.

## 7. Изменение и отзыв доступа

Доступ изменяется или отзывается:
- при смене роли;
- при увольнении/окончании договора;
- при завершении работ подрядчика;
- при инциденте безопасности;
- по запросу клиента.

## 8. Доступ к персональным данным

Доступ к ПДн предоставляется только при наличии рабочей необходимости. Избыточный доступ запрещен.

## 9. Контроль

Права доступа подлежат регулярному пересмотру не реже [1 раза в квартал / полугодие].
