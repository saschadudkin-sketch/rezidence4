# Security Overview DomHub

## 1. Назначение

Документ описывает верхнеуровневый подход к безопасности платформы DomHub.

## 2. Архитектура

- многообъектная платформа с логической изоляцией объектов;
- разграничение ролей и scope;
- централизованное журналирование действий;
- защищённые каналы передачи данных;
- контроль доступа на уровне приложения и инфраструктуры.

## 3. Защита данных

- ограничение доступа по ролям;
- ведение аудита действий;
- резервное копирование;
- контроль внешних обработчиков;
- меры по защите персональных данных и конфиденциальной информации.

## 4. Инфраструктура

- размещение в согласованной инфраструктуре;
- контроль секретов и ключей;
- мониторинг доступности и состояния сервиса;
- управление уязвимостями и обновлениями.

## 5. Реагирование

Используется внутренняя процедура реагирования на инциденты, включая уведомление клиента по согласованным правилам.

## 6. Подрядчики и внешние сервисы

Внешние сервисы подключаются по необходимости и контролируются договорными и организационными мерами.
