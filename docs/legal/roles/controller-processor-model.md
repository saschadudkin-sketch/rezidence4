# Модель ролей оператора и обработчика персональных данных

## 1. Общая логика

Для DomHub должна быть отдельно определена модель, в которой по разным процессам стороны могут выступать:
- оператором персональных данных;
- лицом, осуществляющим обработку по поручению оператора;
- самостоятельным оператором по отдельным целям.

## 2. Базовая модель

В типовом сценарии:
- управляющая компания или клиент выступает оператором данных жителей и сотрудников объекта;
- DomHub выступает обработчиком по поручению в части предоставления платформы;
- DomHub может быть самостоятельным оператором для данных, необходимых для исполнения договора, безопасности, поддержки, биллинга и журналирования.

## 3. Что нужно формализовать

- перечень процессов, где DomHub является обработчиком;
- перечень процессов, где DomHub является самостоятельным оператором;
- состав передаваемых данных;
- цели обработки;
- сроки хранения;
- порядок удаления и возврата данных;
- порядок работы с субобработчиками.
